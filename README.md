# Fe — أطلس فشل السبائك

مخطّط تفاعلي ثلاثي الأبعاد لأنماط فشل المعادن والسبائك تحت الأحمال والبيئات المختلفة: الفولاذ غير
القابل للصدأ، والفولاذ الكربوني، وحديد الزهر، والألمنيوم، والنحاس وسبائكه، والتيتانيوم، ولحام القصدير.

اختر سبيكة من ثماني عشرة، واختر نمط فشل من اثني عشر، ثم حرّك الشريط وشاهد العيّنة تستطيل وتُعنَق وتنكسر —
أو تتآكل وتتشقّق — مع الأرقام والمنحنى الهندسي المقابل لكل حالة.

## الفكرة التي يُعلّمها التطبيق

الفولاذ «غير القابل للصدأ» نادرًا ما يفشل لأن الحمل تجاوز متانته. يفشل لأن طبقة أوكسيد الكروم التي
تحميه هُزمت — أو لأن الزمن والحرارة وتَكرار الدورات فعلت ما عجز عنه الحمل. لذلك تجد هنا الشدّ
والانحناء واللَّي إلى جانب التآكل النقري وتشقّق الكلوريدات والتحسّس وتقصّف الهيدروجين، في مكان واحد.

## أنماط الفشل

**ميكانيكية:** الشدّ · الضغط والانبعاج · الانحناء · اللَّي · القصّ المباشر · الكلال · الزحف · الصدم ودرجة الانتقال

**بيئية:** التآكل النقري · التشقّق الإجهادي بالكلوريد · التحسّس والتآكل بين-الحبيبي · تقصّف الهيدروجين

## الفيزياء

لا شيء في الحركة «مرسوم بالعين». كل منحنى مشتقّ من علاقة منشورة:

- **منحنى الشدّ** — تصلّد Hollomon على محور الإجهاد الحقيقي مع إزاحة تجعل المنحنى يمرّ بـ Rp0.2 وRm
  المنشورتين بالضبط. بدء العنق بمعيار Considère.
- **الكلال** — منحنى S–N مثبّت عند 0.9·Rm لألف دورة وعند مقاومة الكلال المنشورة لعشرة ملايين، مع
  نمو الشقّ بقانون Paris.
- **الزحف** — معامل Larson-Miller معايَر على بيانات انهيار 304 المنشورة (65 MPa عند 600 °م ≈ 10⁵ ساعة).
- **الصدم** — منحنى انتقال على شكل S للبنى BCC، ومسطّح للبنى FCC.
- **النقر** — ‏PREN = ‎%Cr + 3.3%Mo + 16%N، ومنه CPT، ثم تعمّق محكوم بالانتشار (‎√t‎).
- **SCC** — مثلّث الشروط مع علاقة Arrhenius، وعتبة حرارة تتبع قابلية السبيكة.
- **التحسّس** — منحنى TTT على شكل C، أنفه عند 700 °م، وزمنه يتبع محتوى الكربون والتثبيت.
- **الهيدروجين** — إجهاد عتبة يهبط مع التركيز، متدرّجًا بالقساوة والبنية البلورية.

يتحقّق `npm run verify:engine` من 146 توكيدًا على هذه القيم مقابل المنشور.

## التشغيل

```bash
npm install
npm run dev              # خادم التطوير
npm run build            # فحص الأنواع + بناء الإنتاج
npm run verify:engine    # فحص الفيزياء مقابل القيم المنشورة
npm run verify:view      # يشغّل البناء في متصفّح حقيقي ويلتقط كل نمط
```

`verify:view` يحتاج بناءً جاهزًا في `dist/`، ويلتقط الصور في `.shots/`.

## القيود المقصودة

- **لا ملفّات نماذج ثلاثية الأبعاد.** كل الهندسة مُولَّدة برمجيًّا: العيّنة نصفان متناظران يلتقيان عند
  مستوى الكسر، وكل تشوّه يقع في vertex shader.
- **لا تخزين في المتصفّح.** لا `localStorage` ولا كوكيز.
- **لا موارد شبكة وقت التشغيل.** بيئة الإضاءة مُولَّدة من `RoomEnvironment` ومُرشَّحة على البطاقة عند الإقلاع.
- **كل الأبعاد بالمليمتر** في `src/data/`، وتُحوَّل مرّة واحدة بـ `SCENE_SCALE`.
- **المصطلحات التقنية بالإنجليزية كما تكتبها المعايير**، والشرح بالعربية الفصحى. اللوحات RTL واللوحة
  ثلاثية الأبعاد LTR.
